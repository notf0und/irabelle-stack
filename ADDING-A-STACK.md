# Adding a stack

A stack is a directory at the top of this checkout with a `compose.yml` in it.
`setup.sh`, `update.sh`, `stacks.sh` and `fast-disk.sh` all find stacks that
way, so none of them needs editing for a new one. What does need doing is
below, in order. The `arr` and `books` stacks are the worked examples: when a
step here is unclear, look at how they do it.

The one exception is `dsh/`: the DeepSeek Harness refuses to bind anything but
loopback, so it is a host systemd *user* service with a bridge in front of it,
provisioned by `dsh/install.sh` (called from `setup.sh`) and documented in
`dsh/README.md`. Nothing here applies to it — it has no `compose.yml`, no
`config/`, and is not deployed from Dockhand.

Throughout, `myapp` is the new stack, `<TLD>` your domain (`smart`), and
`myapp.<TLD>` the name it is published under.

## 1. Pick the name

The directory name is also the hostname: `myapp/` is served as
`https://myapp.<TLD>`. Keep it short, lowercase, no dots.

`.smart` is a real, delegated TLD (see
[Why `.smart`](README.md#why-smart)), so check the name is not something
Smart Communications runs before you use it — a device off your network would
reach theirs instead:

```sh
dig +short myapp.smart @1.1.1.1     # must come back empty
```

## 2. Write `myapp/compose.yml`

Start from this; every line is there for a reason explained after it.

```yaml
services:
  myapp:
    image: example/myapp:latest
    container_name: myapp
    # As you, where the image allows it (PUID/PGID for LinuxServer images):
    # its files in config/ stay yours to edit and delete.
    user: "${PUID:-1000}:${PGID:-1000}"
    env_file:
      - path: .env
        required: false
    environment:
      TZ: ${TZ:-Pacific/Auckland}
      MYAPP_SECRET: ${MYAPP_SECRET:?MYAPP_SECRET is unset - run ./setup.sh, or set it in myapp/.env}
    volumes:
      - ./config/myapp:/config
      # Only if it handles media: the whole tree, at the same path as every
      # other stack uses, so paths match and hardlinks work.
      #- ../downloads:/data/downloads
    networks:
      - app-bridge
    labels:
      traefik.enable: true
      traefik.http.services.myapp.loadbalancer.server.port: 8080
      traefik.http.routers.myapp.rule: Host("myapp.${TLD:?TLD is not set in .env (see .env.example)}")
      traefik.http.routers.myapp.entrypoints: web
      traefik.http.routers.myapp.service: myapp
      traefik.http.routers.myapp.middlewares: myapp
      traefik.http.middlewares.myapp.redirectscheme.scheme: https
      traefik.http.routers.myapp-https.rule: Host("myapp.${TLD:?TLD is not set in .env (see .env.example)}")
      traefik.http.routers.myapp-https.entrypoints: websecure
      traefik.http.routers.myapp-https.service: myapp
      traefik.http.routers.myapp-https.tls: true
      # Step 5 decides whether this line stays:
      traefik.http.routers.myapp-https.middlewares: authentik@docker
    restart: unless-stopped

networks:
  app-bridge:
    external: true
    driver: bridge
```

* **`container_name` = the service name.** Other containers reach it as
  `http://myapp:<port>` over `app-bridge`, and `integrations.py` finds it by
  that name.
* **`env_file` optional**, so a git-based deploy (no `.env`, values from
  Dockhand's environment panel) is not an error.
* **`${VAR:?message}`** for anything that must be set: compose refuses to start
  with a clear error instead of running with an empty secret.
* **State under `./config/<service>/`**, one directory per service (a stack
  with a database has `config/myapp` and `config/myapp-db`). That single
  `config/` is what `fast-disk.sh` moves to the SSD and what `.gitignore`
  keeps out of git — so never put state anywhere else in the stack, and never
  in a named volume.
* **Only the full name** (`myapp.<TLD>`) in the `Host()` rules. A bare `myapp`
  cannot carry the authentik login. `cert-watcher.sh` reads these rules to
  issue the certificate, so it needs nothing from you.
* **A private network for a database**, never `app-bridge`: only the app joins
  it (see `lingarr`/`lingarr-db` in `arr/compose.yml`).
* **No published ports** unless something truly cannot go through Traefik
  (torrent peers, DNS, a device's raw protocol). A published port bypasses
  TLS and the login.

Check it: `(cd myapp && TLD=smart docker compose config -q)`.

## 3. `myapp/.env.example` — only if it needs its own variables

Without one, `setup.sh` gives the stack a copy of the root `.env` (TLD, TZ,
PUID, PGID). With one, it uses this instead:

```sh
# myapp stack — what it is, one line.
#
# ./setup.sh copies this to myapp/.env, and adds any key an older .env is
# missing. myapp/.env is gitignored.

# Only ever set in the root .env.example; @TLD@ is expanded from it.
TLD=@TLD@
TZ=Pacific/Auckland
PUID=1000
PGID=1000

# `change-me` = generated by ./setup.sh on first run.
MYAPP_SECRET=change-me
```

* **`@TLD@`, never a literal** — renaming the domain then means one edit.
* **`change-me`** for every secret and API key. If the app can take its API key
  from the environment (the *arrs do: `SONARR__AUTH__APIKEY`), generate it here
  and hand it over — then nothing ever has to read it back out of the app.
* Adding a key later is fine: `setup.sh` appends it to existing `.env` files.

## 4. Keep its state out of git

In `.gitignore`, one line per service, next to the others:

```gitignore
**/config/myapp/*
```

A config file you want *tracked* but editable per install (like
`traefik.yml`) is committed as `<file>.example`, copied into place by
`setup.sh` (the `for f in traefik/config/traefik.yml ...` list), and its real
name gitignored. A file the stack only reads and you never edit can simply be
committed.

## 5. The login

Every web UI is behind authentik. Pick the first that fits:

**a. The app speaks OIDC** (Kavita, Shelfmark, Cleanuparr, Dockhand): drop the
`authentik@docker` middleware line, and

1. add a client to `authentik/config/authentik/blueprints/irabelle.yaml` —
   copy the Shelfmark block: an `oauth2provider` (`client_id: myapp`, its
   redirect URI, `grant_types`, the `email-verified` mapping), its
   `application`, and the `policybinding` to `authentik Admins`;
2. add `MYAPP_OIDC_CLIENT_SECRET=change-me` to `authentik/.env.example`, pass it
   to the **worker** in `authentik/compose.yml`, and read it in the blueprint's
   `context:` with `!Env`;
3. set the app's side in `integrations.py` (step 6): issuer
   `https://authentik.<TLD>/application/o/myapp/`, client id `myapp`, the
   secret from `authentik/.env`;
4. make it trust the root CA — it checks the login server-side over
   `https://authentik.<TLD>`: mount
   `../traefik/generate_certificates/root-certificates:/certificates:ro` and
   point it at `ca-bundle.crt` (`SSL_CERT_FILE` for .NET and OpenSSL,
   `REQUESTS_CA_BUNDLE` for Python requests), or for a LinuxServer image mount
   `root-ca.crt` plus `books/scripts/kavita/10-update-ca-certificates.sh`.

The login links to the account `integrations.py` makes for you by **email**,
so create that account with `ADMIN_EMAIL`.

**b. The app has no login, or can switch it off** (Sonarr, Bazarr, Lingarr):
keep `authentik@docker`, turn the app's own login off (or to "External"), and
in the blueprint

1. add a `proxyprovider` in `forward_single` mode for
   `https://myapp.<TLD>`, its `application` and `policybinding` — copy the
   Sonarr block;
2. **add the provider to the embedded outpost's `providers:` list** at the end
   of the blueprint. Forget this and the login never works for it.

If it has an API other programs call, route that path around authentik, next to
the https router (the API key protects it):

```yaml
      traefik.http.routers.myapp-api.rule: Host("myapp.${TLD:?...}") && PathPrefix("/api")
      traefik.http.routers.myapp-api.entrypoints: websecure
      traefik.http.routers.myapp-api.service: myapp
      traefik.http.routers.myapp-api.tls: true
```

**c. Its clients cannot do a web login at all** (Plex apps, e-readers): no
middleware, and make sure the app's own authentication is on.

## 6. Wire it to the other apps — `integrations.py`

If it needs anything from, or to be known by, another app (an API key, a
download client, a library), add a section to `integrations.py` rather than
documenting clicks:

```python
@section("MyApp", needs=[("myapp", 8080, "/health")])
def myapp(myapp):
    api = Api(myapp + "/api", {"X-Api-Key": read_env("myapp")["MYAPP_API_KEY"]})
    if not any(c["name"] == "Sonarr" for c in api.get("/connections")):
        api.post("/connections", {...})
        note("Sonarr connected")
    else:
        note("Sonarr connected already")
```

The rules the existing sections keep to:

* **add, never change**: look first, create only what is missing, so a
  setting changed in the app's UI stays changed and a re-run is a no-op;
* **only what is running**: `@section(needs=...)` skips the app if its
  container is not up, and waits for it to answer if it is;
* **other apps by container name** (`http://sonarr:8989`), never through
  Traefik;
* **a local account** for apps with a login of their own: `USER`, `PASSWORD`
  and `EMAIL` from `authentik/.env`, so there is a way in while authentik is
  down.

It runs at the end of `setup.sh`, on every `update.sh` run, and by hand.

## 7. Deploy it

```sh
git add myapp .gitignore authentik && git commit && git push
```

Then, on the host:

```sh
./setup.sh           # creates myapp/.env and its config/ folders, moves config/
                     # to the fast disk if you use one, adopts it into Dockhand
```

Deploy **myapp** from Dockhand (it is already in the list), then:

```sh
./integrations.py    # wire it now instead of at the next update.sh run
```

`cert-watcher.sh` issues `myapp.<TLD>`'s certificate within seconds of the
container starting.

## 8. Check it

* `https://myapp.<TLD>` sends you to authentik, and after that login you are
  in — without a second one;
* for OIDC apps, you are the same user as the account `integrations.py`
  created, not a second one next to it;
* `./integrations.py` run twice: the second run changes nothing;
* `./fast-disk.sh status` lists `myapp/config` on the fast disk (if you use
  one);
* `git status` is clean after it has run — if not, step 4 missed something.

## 9. Document it

In `README.md`: the stack table and the file tree near the top, the
Dockhand environment-panel table (if it has an `.env.example`), and the
repository-hygiene table (its `config/` line). If it is a media app, its row in
[Media apps](README.md#media-apps-wired-together-and-behind-authentik).
